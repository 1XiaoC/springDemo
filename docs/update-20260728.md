### 1. Result.java — 统一返回结果类

**文件路径：** [common/Result.java](file:///c:/Users/27019/Desktop/测试文件夹/springDemo/src/main/java/com/example/springdemo/common/Result.java)

**完整代码：**

```java
package com.example.springdemo.common;

import lombok.Data;
import java.io.Serializable;

@Data
public class Result implements Serializable {
    private static final long serialVersionUID = 1L;
    private Integer code;   // 状态码
    private String msg;     // 提示信息
    private Object data;    // 返回数据

    // 成功：带数据
    public static Result success(Object data) { ... }
    // 成功：自定义状态码、消息、数据
    public static Result success(int code, String msg, Object data) { ... }
    // 成功：无数据
    public static Result success() { ... }
    // 失败：默认
    public static Result error() { ... }
    // 失败：自定义消息
    public static Result error(String msg) { ... }
    // 失败：自定义状态码、消息、数据
    public static Result error(int code, String msg, Object data) { ... }
}
```

---

#### 注解说明

| 注解 | 所属包 | 作用 |
|------|--------|------|
| `@Data` | `lombok.Data` | Lombok 提供的组合注解，自动生成类中所有属性的 `getter`、`setter`、`toString()`、`equals()`、`hashCode()` 方法，省去手动编写模板代码 |

---

#### 关键字/接口说明

| 名称 | 类型 | 作用 |
|------|------|------|
| `Serializable` | 接口 | Java 序列化接口，实现该接口表示该类对象可以被序列化（转为字节流），便于网络传输或缓存存储 |
| `serialVersionUID` | 静态常量 | 序列化版本号，用于验证序列化和反序列化时类版本是否一致，避免版本不兼容导致的异常 |

---

#### 类属性说明

| 属性 | 类型 | 说明 |
|------|------|------|
| `code` | `Integer` | 响应状态码，如 200 表示成功，400/500 表示失败 |
| `msg` | `String` | 响应提示信息，如 "操作成功"、"操作失败" |
| `data` | `Object` | 响应数据，存放具体的返回内容（用户数据、列表等） |

---

#### 静态方法说明

| 方法 | 返回值 | 参数 | 说明 |
|------|--------|------|------|
| `success(Object data)` | `Result` | `data` - 返回数据 | 快速返回成功结果，默认 code=200，msg="操作成功" |
| `success(int code, String msg, Object data)` | `Result` | `code` 状态码, `msg` 提示, `data` 数据 | 完全自定义成功返回 |
| `success()` | `Result` | 无 | 返回成功但不携带数据 |
| `error()` | `Result` | 无 | 默认失败返回，code=400，msg="操作失败" |
| `error(String msg)` | `Result` | `msg` - 错误信息 | 返回失败并自定义错误消息 |
| `error(int code, String msg, Object data)` | `Result` | `code` 状态码, `msg` 错误信息, `data` 数据 | 完全自定义失败返回 |

---

#### 作用与意义

1. **统一响应格式**：所有接口返回相同的数据结构（code + msg + data），前端解析方便
2. **简化代码**：Controller 层直接调用 `Result.success(data)` 即可返回标准格式
3. **易于扩展**：后续可在 Result 类中添加更多字段（如时间戳、请求ID等）
4. **前后端协作**：约定统一的接口规范，减少联调沟通成本

---

#### 使用示例

```java
// 成功返回数据
@GetMapping("/user/{id}")
public Result getUser(@PathVariable Long id) {
    User user = userMapper.selectById(id);
    return Result.success(user);
}

// 返回格式
// {
//   "code": 200,
//   "msg": "操作成功",
//   "data": { "id": 1, "name": "小明", "age": 20 }
// }

// 失败返回
@PostMapping("/user")
public Result addUser(@RequestBody User user) {
    if (user.getName() == null) {
        return Result.error("用户名不能为空");
    }
    userMapper.insert(user);
    return Result.success();
}
```

### 2. GlobalExceptionHandler.java — 全局异常处理器

**文件路径：** [handler/GlobalExceptionHandler.java](file:///c:/Users/27019/Desktop/测试文件夹/springDemo/src/main/java/com/example/springdemo/handler/GlobalExceptionHandler.java)

**当前代码：**

```java
package com.example.springdemo.handler;

import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {
}
```

---

#### 注解说明

| 注解 | 所属包 | 作用 |
|------|--------|------|
| `@RestControllerAdvice` | `org.springframework.web.bind.annotation.RestControllerAdvice` | Spring MVC 提供的注解，是 `@ControllerAdvice` + `@ResponseBody` 的组合。用于全局异常处理，捕获 Controller 层抛出的异常并统一返回 JSON 格式的响应 |

**`@RestControllerAdvice` 的核心特性：**
- **全局捕获**：自动扫描所有 `@RestController` 类，拦截其抛出的异常
- **返回 JSON**：方法返回值自动序列化为 JSON，与 `@ResponseBody` 效果相同
- **AOP 思想**：基于 Spring AOP 实现，不侵入业务代码

---

#### 作用与意义

1. **统一异常处理**：所有 Controller 层的异常统一在一个地方处理，避免每个方法单独 try-catch
2. **标准化错误响应**：异常返回也遵循 Result 统一格式，前端统一处理
3. **保护内部信息**：避免将堆栈信息直接暴露给前端，只返回友好的错误提示
4. **便于维护**：异常处理逻辑集中管理，修改异常策略只需改一处

---

#### 后续扩展方向

后续可在类中添加异常处理方法，例如：

```java
// 捕获系统异常
@ExceptionHandler(Exception.class)
public Result handleException(Exception e) {
    return Result.error(500, "系统异常：" + e.getMessage(), null);
}

// 捕获业务异常
@ExceptionHandler(BusinessException.class)
public Result handleBusinessException(BusinessException e) {
    return Result.error(e.getCode(), e.getMessage(), null);
}

// 捕获参数校验异常
@ExceptionHandler(MethodArgumentNotValidException.class)
public Result handleValidException(MethodArgumentNotValidException e) {
    String msg = e.getBindingResult().getFieldError().getDefaultMessage();
    return Result.error(400, msg, null);
}
```
