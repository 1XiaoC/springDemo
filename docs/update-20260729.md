## 一、GlobalExceptionHandler.java — 全局异常处理器

**文件路径：** [handler/GlobalExceptionHandler.java](file:///c:/Users/27019/Desktop/测试文件夹/springDemo/src/main/java/com/example/springdemo/handler/GlobalExceptionHandler.java)

### 完整代码

```java
package com.example.springdemo.handler;

import com.example.springdemo.common.Result;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(RuntimeException.class)
    public Result handlerException(RuntimeException e) {
        return Result.error(e.getMessage());
    }
}
```

---

### 1.1 注解详解

| 注解 | 所属包 | 作用 |
|------|--------|------|
| `@RestControllerAdvice` | `org.springframework.web.bind.annotation` | **组合注解** = `@ControllerAdvice` + `@ResponseBody`<br>① `@ControllerAdvice`：基于 AOP 思想，全局拦截所有 `@Controller` / `@RestController` 类<br>② `@ResponseBody`：方法返回值自动序列化为 JSON |
| `@ExceptionHandler(RuntimeException.class)` | `org.springframework.web.bind.annotation` | 标记方法为**异常处理器**，参数 `value` 指定要捕获的异常类型（含子类）<br>匹配规则：优先匹配最精确的异常类型，无匹配则向上找父类 |

### 1.5 标准使用示例

```java
@Service
public class UserServiceImpl implements UserService {

    @Resource
    private UserMapper userMapper;

    /**
     * 标准示例1：业务校验抛出 RuntimeException
     */
    public User getUserById(Long id) {
        if (id == null || id <= 0) {
            // 直接抛异常，无需 try-catch，全局处理器会处理
            throw new RuntimeException("用户ID不合法：" + id);
        }
        User user = userMapper.selectById(id);
        if (user == null) {
            throw new RuntimeException("用户不存在，ID: " + id);
        }
        return user;
    }

    /**
     * 标准示例2：新增用户校验
     */
    public void addUser(User user) {
        if (user.getName() == null || user.getName().trim().isEmpty()) {
            throw new RuntimeException("用户名不能为空");
        }
        if (user.getAge() != null && (user.getAge() < 0 || user.getAge() > 150)) {
            throw new RuntimeException("年龄不合法");
        }
        userMapper.insert(user);
    }
}
```

**Controller 层无需 try-catch：**

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @Resource
    private UserService userService;

    @GetMapping("/{id}")
    public Result getById(@PathVariable Long id) {
        // 这里不需要 try-catch！抛异常会被自动处理
        User user = userService.getUserById(id);
        return Result.success(user);
    }
}
```

### 2.1 继承关系详解

| 接口 | 所属包 | 作用 |
|------|--------|------|

**`IService` 内置常用方法一览（继承即拥有）：**

| 方法分类 | 方法签名 | 作用 |

| 查询 | `<E extends IPage<T>> E page(E page, Wrapper<T> queryWrapper)` | 分页查询 |
| 查询 | `long count()` | 统计总数 |
| 新增 | `boolean save(T entity)` | 插入一条 |
| 新增 | `boolean saveBatch(Collection<T> entityList)` | 批量插入 |
| 修改 | `boolean updateById(T entity)` | 根据主键更新 |
| 修改 | `boolean update(T entity, Wrapper<T> updateWrapper)` | 条件更新 |
| 删除 | `boolean removeById(Serializable id)` | 根据主键删除 |
| 删除 | `boolean removeByIds(Collection<? extends Serializable> list)` | 批量删除 |

### 3.2 标准 Service 层写法（推荐参考）

```java
package com.example.springdemo.service.impl;

import com.baomidou.mybatisplus.spring.service.impl.ServiceImpl;
import com.example.springdemo.entity.User;
import com.example.springdemo.mapper.UserMapper;
import com.example.springdemo.service.UserService;
import jakarta.annotation.Resource;
import org.springframework.stereotype.Service;

/**
 * 标准写法：
 * 1. 加 @Service 注解，让 Spring 扫描生成 Bean
 * 2. 继承 ServiceImpl<Mapper, Entity>，自动实现 IService 的方法
 * 3. 实现 UserService 接口
 */
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, User> implements UserService {

    @Resource
    private UserMapper userMapper;

    /**
     * 自定义业务方法：根据ID查询用户（带校验）
     */
    public User getUserByIdWithCheck(Long id) {
        if (id == null || id <= 0) {
            throw new RuntimeException("用户ID不合法");
        }
        // 方式1：调用继承来的 getById（来自 IService）
        User user = this.getById(id);
        // 方式2：调用 mapper 原生方法
        // User user = userMapper.selectById(id);
        if (user == null) {
            throw new RuntimeException("用户不存在，ID: " + id);
        }
        return user;
    }

    /**
     * 自定义业务方法：新增用户（带校验）
     */
    public void addUserWithCheck(User user) {
        if (user.getName() == null || user.getName().isEmpty()) {
            throw new RuntimeException("用户名不能为空");
        }
        this.save(user); // 调用 IService 内置的 save
    }
}
```

## 五、完整标准示例

### 5.1 Controller 层写法（推荐）

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @Resource
    private UserService userService; // 改为注入 Service，不再直接用 Mapper

    /**
     * 新增用户
     * POST /dev-api/user/user
     * Body: {"name":"小明","age":20,"email":"xiaoming@qq.com"}
     */
    @PostMapping("/user")
    public Result save(@RequestBody User user) {
        userService.addUserWithCheck(user);
        return Result.success();
    }

    /**
     * 查询所有用户（分页）
     * GET /dev-api/user/user
     */
    @GetMapping("/user")
    public Result getAll() {
        Page<User> page = userService.page(new Page<>(1, 10));
        return Result.success(page);
    }

    /**
     * 根据ID查询用户
     * GET /dev-api/user/user/1
     */
    @GetMapping("/user/{id}")
    public Result get(@PathVariable Long id) {
        User user = userService.getUserByIdWithCheck(id);
        return Result.success(user);
    }

    /**
     * 修改用户
     * PUT /dev-api/user/user/1
     */
    @PutMapping("/user/{id}")
    public Result update(@PathVariable Long id, @RequestBody User user) {
        user.setId(id);
        userService.updateById(user); // 调用 IService 内置方法
        return Result.success();
    }

    /**
     * 删除用户
     * DELETE /dev-api/user/user/1
     */
    @DeleteMapping("/user/{id}")
    public Result delete(@PathVariable Long id) {
        userService.removeById(id); // 调用 IService 内置方法
        return Result.success();
    }
}
```
