## 详细更新说明

### 1. pom.xml — 新增 mybatis-plus-jsqlparser 依赖

**修改内容：**

```xml
<!-- MyBatis-Plus JSqlParser 支持，用于多租户、数据权限等需要解析 SQL 的功能 -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-jsqlparser</artifactId>
</dependency>
```

**作用：**

- **JSqlParser** 是一个 SQL 解析器库，可以将 SQL 语句解析成语法树，方便进行动态修改
- MyBatis-Plus 的部分高级功能（如 **多租户插件**、**数据权限插件**、**动态表名** 等）依赖此库进行 SQL 解析和改写
- 提前引入该依赖，为后续业务扩展（如多租户系统、数据行级权限控制）打下基础

---

### 2. MyBatisPlusConfig.java — 配置分页插件

**修改内容：**

```java
@Bean
public MybatisPlusInterceptor mybatisPlusInterceptor(){
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
    return interceptor;
}
```

**作用：**

- 注册 `MybatisPlusInterceptor` 拦截器到 Spring 容器
- 添加 `PaginationInnerInterceptor` 分页内部拦截器，指定数据库类型为 `MYSQL`
- **核心效果**：使得 `BaseMapper.selectPage()` 分页方法能够自动生成 `LIMIT` 分页 SQL，否则调用分页方法只会返回全量数据，不会真正分页
- `DbType.MYSQL` 用于告诉插件使用 MySQL 的分页语法（`LIMIT offset, size`）

---

### 3. UserController.java — 查询接口改为分页查询

**修改内容：**

```java
/* 修改前 */
@GetMapping("/user")
public List<User> getAll() {
    return userMapper.selectList(new LambdaQueryWrapper<>());
}

/* 修改后 */
@GetMapping("/user")
public Page<User> getAll() {
    return userMapper.selectPage(new Page<User>(1, 10), new LambdaQueryWrapper<>());
}
```

**作用：**

- 返回值从 `List<User>` 改为 `Page<User>`，返回完整的分页信息（当前页、每页大小、总记录数、总页数、数据列表等）
- 使用 `selectPage(page, wrapper)` 替代 `selectList(wrapper)`，实现分页查询
- 当前默认查询第 1 页，每页 10 条数据
- **优势**：数据量大时避免一次性加载全部数据，减轻数据库和内存压力，提升接口响应速度

**分页返回数据结构示例：**

```json
{
  "records": [
    { "id": 1, "name": "小明", "age": 20, "email": "xiaoming@example.com" },
    { "id": 2, "name": "小红", "age": 22, "email": "xiaohong@example.com" }
  ],
  "total": 100,
  "size": 10,
  "current": 1,
  "pages": 10
}
```

### 4. User.java — 时间字段格式化

**修改内容：**

```java
@JsonFormat(pattern = "yyyy-MM-dd")
@TableField(value = "create_time")
private LocalDateTime createTime;

@JsonFormat(pattern = "yyyy-MM-dd")
@TableField(value = "update_time")
private LocalDateTime updateTime;
```

**作用：**

- `@JsonFormat` 是 Jackson 提供的注解，用于控制 Java 对象序列化为 JSON 时的格式
- `pattern = "yyyy-MM-dd"` 指定日期输出格式为 **年-月-日**，例如 `2026-07-25`
- **解决问题**：默认情况下 `LocalDateTime` 序列化为 JSON 时格式复杂（含时分秒和时区），前端展示不友好，通过此注解统一日期显示格式
- 仅影响 JSON 输出格式，不影响数据库存储
